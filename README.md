# Hamzury Holding

Corporate website, client journey and staff workspace.

## Getting started

Requires [Node.js](https://nodejs.org) 18 or newer.

```sh
npm install
npm run dev
```

`npm run dev` serves `src/` at http://localhost:8000 and reloads the browser whenever a file changes.

| Command           | What it does                                                |
| ----------------- | ----------------------------------------------------------- |
| `npm run dev`     | Live-reloading dev server on `src/`                         |
| `npm run build`   | Runs the checks and builds the deployable site into `dist/` |
| `npm run preview` | Serves the built `dist/` at http://localhost:8001           |
| `npm run check`   | Checks every script parses and every linked file exists     |
| `npm run format`  | Formats `src/` with Prettier                                |

Edit files in `src/` only. `dist/` is generated by `npm run build` and is not committed.

## Project layout

```
src/
  index.html          corporate homepage
  services.html       all six ventures
  venture.html        one venture (?v=bizdoc|medialy|subt|iotics|hub|iwiin)
  about.html          about Hamzury
  contact.html        ways to get in touch
  app.html            client journey (discovery, progress) + staff workspace
  operations.html     operating centre (catalogue, proposals)
  phone-preview.html  app.html inside a phone-sized frame
  scripts/            plain browser scripts (see ARCHITECTURE.md)
  styles/             stylesheets
  assets/             venture logos
scripts/
  build.mjs           src/ -> dist/
  check.mjs           sanity checks
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the scripts fit together.

## Deploying

Netlify runs `npm run build` and publishes `dist/` (see `netlify.toml`). Any other static host works the same way: build, then upload `dist/`.

## Preview limitations

Records stay in the visitor's browser (localStorage and IndexedDB). Role selection is a preview, not access control. Shared accounts, server-side permissions, secure file storage, payments and notifications require backend implementation. Use sample data only.
